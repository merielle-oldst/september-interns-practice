# September Interns — Practice

Hands-on exercises for the **Project Tempo** internship (Old.St Labs). Each week's
exercise lives in its own folder and reinforces that week's masterclass with code
you actually build.

These are **practice exercises**, separate from the capstone (the Team Workload
Planner). They're intentionally small and self-contained so you can focus on one
idea at a time.

## How to use these

1. `cd` into the week's folder and read its `README.md` first.
2. Install and run the tests — it's normal for some to be **red** at the start.
   Turning them green is the exercise.
3. Do the `TODO(intern)` tasks, keep the suite green, then open a **Pull Request**
   for async mentor review.

## The one rule

You must be able to **explain every line you commit**. AI can help you learn and
draft, but if you can't explain it, you don't ship it. The weekly Knowledge Checks
are written and AI-free.
