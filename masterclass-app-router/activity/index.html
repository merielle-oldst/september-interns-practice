Activity: Sketch the Boundary

Four plain HTML/CSS pages — no framework, no JavaScript. Pick one, then decide which visual pieces would be a Server Component and which would need 'use client' if this were rebuilt in Next.js App Router.

How this works

  1. Pick one of the four pages below (don't feel like you need to look at all of them).
  2. Spend 5–10 minutes going section by section: header, main content, any buttons/forms/toggles.
  3. For each piece, decide: does it need state, an event handler, or a browser-only API? If yes → Client. If it's just display → Server.
  4. Be ready to report back in chat — which page you picked, and your reasoning for the trickiest 1–2 elements.
